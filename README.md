# بورتفوليو إسلام ثابت | النسخة الثانية التجريبية

التصميم الأصلي البسيط باللون الفحمي والأخضر الليموني، عربي افتراضيًا، مع زر EN للإنجليزية وزر AR للعودة للعربية. الصورة الجديدة، الأعمال الستة وروابط التواصل موجودة. الفيديوهات تفتح على YouTube أو TikTok أو Instagram، ولا تُرفع ملفات الفيديو إلى الموقع.

## مهم قبل الرفع

هذه نسخة تجريبية مستقلة. لا تغيّر ولا تحذف مستودع `eslamthabet.github.io` الحالي. لا تنقل النسخة الثانية إلى الموقع الأساسي إلا بعد معاينتها والموافقة عليها.

## نشر النسخة التجريبية في مستودع جديد

1. فك ضغط الملف. لا ترفع ZIP نفسه.
2. من حسابك `eslamthabet` على GitHub، اختر `+ → New repository`.
3. اختر اسمًا جديدًا مثل `portfolio-v2`. لو الاسم موجود اختر اسمًا مختلفًا، ولا تستبدل مستودعًا قائمًا.
4. اختر `Public`، ثم `Create repository`. ملفات هذا المستودع وصوره ورقم التواصل ستكون قابلة للقراءة للجميع. لا تضع أسرارًا أو أعمال عملاء غير مسموح بنشرها.
5. اختر رابط رفع ملف موجود في المستودع الفارغ، أو `Add file → Upload files`.
6. اسحب محتويات فولدر الموقع، وليس الفولدر الخارجي: `index.html` و`style.css` و`script.js` و`languages.js` و`socials.js` و`videos.js` و`README.md` وفولدر `assets` بالكامل. ارفع `.nojekyll` أيضًا إن ظهر لك.
7. احفظ بـ `Commit changes` إلى الفرع `main`. تأكد أن `index.html` وفولدر `assets` ظاهرين في الصفحة الرئيسية للمستودع.
8. افتح `Settings → Pages`. اختر `Deploy from a branch` ثم `main` ثم `/(root)` واضغط `Save`.
9. انتظر اكتمال النشر وافتح رابط الموقع الذي يعرضه GitHub في صفحة Pages. هذا موقع تجريبي منفصل، وليس رابط الموقع الأساسي. كل مسارات الصور والملفات نسبية لتعمل داخل مسار المستودع الجديد.
10. جرّب الرابط على الموبايل، زر اللغة، الفيديوهات وواتساب قبل مشاركته. لو ظهر 404، راجع اكتمال النشر في `Actions` ووجود `index.html` في الجذر واختيار الفرع الصحيح. لا تغيّر اسم مستودع الموقع الأساسي.

## إضافة فيديو أو حذفه

كل بيانات الأعمال داخل `videos.js`.

1. ارفع الفيديو على YouTube أو TikTok أو Instagram وخذ رابط مشاهدة كامل يبدأ بـ `https://`. تأكد أنه قابل للمشاهدة للجمهور المقصود، وليس خاصًا.
2. ارفع صورة مصغرة داخل `assets`، مثل `new-video.jpg`.
3. افتح `videos.js` واضغط علامة القلم.
4. انسخ مجموعة كاملة من `{` إلى `},` داخل قائمة `PORTFOLIO_VIDEOS`.
5. عدّل:
   - `title`: الاسم بالعربي.
   - `titleEn`: الاسم بالإنجليزي.
   - `description`: وصف عربي قصير.
   - `descriptionEn`: وصف إنجليزي قصير.
   - `category`: `stories` للحكايات، `cinema` للسينما، `art` للتجارب الفنية.
   - `thumbnail`: مسار الصورة مثل `assets/new-video.jpg`.
   - `url`: رابط مشاهدة YouTube أو TikTok أو Instagram.
6. حافظ على علامات التنصيص الإنجليزية والفواصل. احفظ بـ `Commit changes`.

أول مجموعة تظهر أولاً. لحذف عمل احذف مجموعته كاملة. عند غياب النص الإنجليزي يظهر العربي كبديل. يوجد مثال في تعليق أعلى الملف. اكتب نصوصًا عادية دون أكواد HTML.

## قسم الإعلانات المستقل

القسم ظاهر أسفل مختارات الأعمال ويضم الروابط الإحدى عشرة التي أرسلتها، داخل سلايدر أصغر بكروت طولية وعرضية متنوعة. الأسهم والسحب باللمس يتنقلان بين الأعمال، وزر الإيقاف يوقف الحركة التلقائية. يحترم إعداد تقليل الحركة في الجهاز.

العناوين القصيرة وصفية للعرض، وليست أسماء رسمية للحملات. رابط عم فرغلي لم يُرجع صورة غلاف، لذلك يظهر بكارت نصي واضح بدل صورة غير مرتبطة بالعمل. يمكن استبداله بصورة حقيقية داخل `assets` وتعديل `thumbnail`.

لإضافة أعمال أخرى، أضف مجموعات الإعلانات داخل `window.PORTFOLIO_ADS = [ ... ];` في نهاية `videos.js`، بنفس حقول الاسم والوصف والصورة والرابط. لا تحتاج إلى `category` للإعلانات. استخدم `format: "wide"` لصورة عرضية أو `format: "portrait"` لصورة طولية. الصور محلية ولا تعتمد على روابط صور المنصات المؤقتة. يظهر القسم تلقائيًا طالما يوجد إعلان صالح. حذف كل الإعلانات يخفيه تلقائيًا.

## تعديل البيانات والتصميم

- `index.html`: النصوص العربية الأساسية، الخدمات، العملاء ورابط واتساب.
- `languages.js`: المقابل الإنجليزي للنصوص العربية. عند تعديل جملة ثابتة، عدّلها في الملفين حتى تظل النسختان متطابقتين.
- `videos.js`: الأعمال والإعلانات باللغتين.
- `socials.js`: روابط المنصات، الأيقونات وأعداد المتابعين. عدّل `count` عند تغير العدد، وتاريخ التحديث الظاهر في `index.html`. القيم تقريبية كما تعرضها المنصات وليست عدادات مباشرة. YouTube يعرض المشتركين، والباقي المتابعين. K تعني ألف.
- `style.css`: الألوان والخطوط والتصميم المتجاوب.
- `script.js`: العرض والفلاتر واللغة والسلايدر. لا تحتاج لتعديله عند إضافة أعمال.
- `assets/portrait.jpg`: صورتك الحالية. يمكن استبدالها بصورة JPEG بنفس المسار والاسم.
- الأصول والخطوط محلية. احتفظ برخصة خط Cairo داخل `assets/FONT-LICENSE.txt`.

لا توجد لوحة إدارة أو حسابات أو نظام دفع. التعديل من ملفات GitHub. لا توجد أكواد تتبع مضافة. زر اللغة لا يحفظ الاختيار بعد إعادة تحميل الصفحة، وتبدأ كل زيارة بالعربية.
