# موقع إسلام ثابت | دليل النشر والتعديل

موقع ثابت جاهز، عربي أولاً ومتوافق مع الموبايل. لا يحتاج تثبيت برامج أو تشغيل سيرفر على GitHub Pages. الصور والخطوط موجودة داخل الملفات، والفيديوهات تفتح في صفحاتها الأصلية على YouTube وTikTok.

## قبل البداية

- فك ضغط الملف أولاً. لا ترفع ملف ZIP نفسه على GitHub.
- جرّب فتح `index.html` على الكمبيوتر لمعاينة الموقع.
- استخدم كمبيوتر لرفع الملفات بسهولة. لا تحتاج لشراء دومين.
- انشر هذا البورتفوليو كموقع عرض أعمال فقط. لا يوجد متجر أو دفع أو نظام تسجيل دخول.
- المستودع في الخطوات التالية **Public**. أي شخص يستطيع قراءة الملفات والصور ورقم التواصل الموجود داخلها، وليس فقط مشاهدة الصفحة. لا ترفع كلمات سر أو بيانات خاصة أو أعمال عملاء غير مسموح بنشرها.

## 1. إنشاء حساب ومستودع

1. افتح https://github.com وسجّل حسابًا مجانيًا لو ليس لديك حساب، ثم أكمل تأكيد البريد المطلوب.
2. سجّل اسم المستخدم بالإنجليزية كما يظهر في حسابك. اسم المستخدم ليس اسم العرض.
3. من علامة `+` اختر `New repository`.
4. اكتب اسم المستودع بالشكل `USERNAME.github.io`، مع استبدال `USERNAME` باسم مستخدمك الحقيقي.
   مثال توضيحي فقط: لو اسم مستخدمك `myname` يصبح الاسم `myname.github.io`. لا تستخدم اسم المثال حرفيًا.
5. اختر `Public`، وفعّل `Add README`، ثم `Create repository`.
6. لو عندك بالفعل مستودع بنفس هذا الاسم، لا تمسح محتواه أو تستبدل موقعك الحالي دون مراجعة. مسموح بموقع شخصي واحد لكل حساب بهذا الشكل.

## 2. رفع ملفات الموقع

1. افتح المستودع، ثم `Add file` ثم `Upload files`.
2. اسحب **محتويات** فولدر الموقع بعد فك الضغط إلى نافذة الرفع: `index.html` و`style.css` و`script.js` و`videos.js` و`README.md` وفولدر `assets` بالكامل. الملف `.nojekyll` إضافي ويُرفع أيضًا إن ظهر لك؛ الموقع لا يعتمد عليه للعمل.
3. لا تسحب الفولدر الخارجي نفسه. المطلوب أن يظهر `index.html` مباشرة في الصفحة الأساسية للمستودع، وليس داخل فولدر ثانٍ.
4. حافظ على أسماء الملفات كما هي، خصوصًا `index.html` و`assets`، بحروفها الصغيرة.
5. اكتب وصفًا مثل `Add portfolio website` ثم احفظ الرفع إلى الفرع الرئيسي `main` عبر `Commit changes`. لو ظهر `Propose changes` بدلًا منها، أكمل طلب الدمج ثم `Merge pull request` لإدخال الملفات في `main`.
6. تأكد أن فولدر `assets` يحتوي الصور والخطوط، وأن `index.html` ظاهر بجانبه.

## 3. تشغيل GitHub Pages

1. افتح `Settings` داخل المستودع، ثم `Pages` من القائمة الجانبية.
2. عند `Build and deployment` اختر `Source: Deploy from a branch`.
3. في `Branch` اختر `main` ثم `/(root)` واضغط `Save`.
4. انتظر اكتمال النشر. توثيق GitHub يذكر أن ظهور التحديث قد يستغرق حتى 10 دقائق.
5. ارجع إلى `Settings → Pages`، وافتح رابط الموقع الذي يعرضه GitHub عند اكتمال النشر. هذا هو الرابط الذي ترسله للعملاء، وليس رابط المستودع.
6. جرّب الرابط على الموبايل، واضغط أزرار الفيديوهات وواتساب قبل مشاركته.

لو ظهر خطأ 404: تأكد من تطابق اسم المستودع مع اسم حسابك، ووجود `index.html` في الجذر، واختيار `main` و`/(root)`، ثم انتظر انتهاء النشر. راجع تبويب `Actions` إذا فشل النشر.

## 4. إضافة فيديو جديد بنفسك

كل بيانات المعرض في ملف واحد: **`videos.js`**.

1. ارفع الفيديو على YouTube أو TikTok أولاً، وخذ لينك المشاهدة الكامل. فيديو YouTube غير المدرج يعمل لمن معه الرابط، أما الفيديو الخاص فلا يستطيع العميل فتحه. تأكد من السماح للجمهور المقصود بالمشاهدة.
2. جهّز صورة للفيديو. سمّها بالإنجليزية دون مسافات، مثلاً `new-video.jpg`.
3. افتح فولدر `assets` داخل المستودع، ثم `Add file → Upload files` وارفع الصورة، واحفظ التعديل.
4. ارجع إلى `videos.js` واضغط علامة القلم للتعديل.
5. انسخ مجموعة فيديو موجودة كاملة من `{` إلى `},`، والصقها بعد السطر `window.PORTFOLIO_VIDEOS = [` مباشرة لو أردت أن تظهر أولاً.
6. عدّل الحقول الأربعة:
   - `title`: عنوان الفيديو.
   - `description`: وصف قصير للعمل.
   - `thumbnail`: مسار الصورة، مثل `assets/new-video.jpg`.
   - `url`: رابط مشاهدة YouTube أو TikTok الكامل، ويبدأ بـ `https://`.
7. حافظ على علامات التنصيص الإنجليزية والفاصلة بعد كل حقل وبعد القوس الأخير. يوجد مثال مشروح بالتعليقات أعلى الملف.
8. احفظ بـ `Commit changes` إلى `main`، ثم انتظر إعادة النشر. لو استخدمت طلب دمج، ادمجه أولاً.
9. افتح الموقع وحدّثه. لو ظلت النسخة القديمة ظاهرة، جرّب تحديثًا قويًا بـ `Ctrl + Shift + R` أو افتحه في نافذة خاصة.

لحذف فيديو: احذف مجموعته كاملة من `{` إلى `},` فقط. لتغيير الترتيب: انقل المجموعة كاملة. عدد الأعمال يتحدث تلقائيًا.

لا ترفع ملف الفيديو الكبير إلى المستودع. الموقع يستخدم صورة ورابط مشاهدة، وليس مساحة رفع فيديوهات. الرفع من متصفح GitHub محدود بـ25 MiB للملف الواحد و100 ملف في المرة، وملفات هذا الموقع أصغر من ذلك بكثير.

## 5. تغيير صورتك أو بياناتك

- صورتك الحالية في `assets/portrait.jpg`. لاستبدالها، ارفع صورة JPEG جديدة بنفس الاسم والمسار، ثم احفظ. صور عمودية واضحة تناسب الإطار أكثر.
- الاسم والخدمات والعملاء والتواصل موجودة داخل `index.html`.
- الألوان والمسافات والخطوط موجودة داخل `style.css`.
- لا تحتاج لتعديل `script.js` لإضافة أعمال.
- زر واتساب يحتوي رقم التواصل الذي اخترته. لو غيرت رقمك عدّل رابط الزر داخل `index.html`، ثم اختبره من الموبايل.
- لا توجد لوحة إدارة أو كلمات مرور مخفية. التعديل يتم من الملفات على GitHub.

## الملفات

```text
index.html       الصفحة الرئيسية وبياناتك
style.css        التصميم المتجاوب
videos.js        عدّل هذا الملف لإدارة الفيديوهات
script.js        عرض الفيديوهات تلقائيًا
assets/          صورتك وصور الأعمال والخطوط
.nojekyll        يمنع معالجة Jekyll غير المطلوبة
README.md        هذا الدليل
```

## ملاحظات النشر والخصوصية

- روابط الفيديوهات تفتح في نافذة جديدة. لا يوجد تشغيل مدمج داخل الصفحة أو تشغيل تلقائي.
- لا يجمع الموقع رسائل العملاء أو بياناتهم، ولا يحتوي أكواد تتبع. خدمات GitHub وYouTube وTikTok وMeta لها سياساتها الخاصة، ويسجّل GitHub عنوان IP للزائر لأسباب أمنية حسب توثيقه.
- المعرض الحالي لا يدّعي أن مشاهد الذكاء الاصطناعي لقاءات حقيقية، ولا يستخدم أرقام مشاهدات أو شهادات عملاء غير موثقة.
- لا توجد رسوم دومين أو استضافة مطلوبة للإعداد الموضح باستخدام خطة GitHub المجانية لمستودع عام. راجع حدود وسياسات GitHub Pages قبل إضافة متجر أو مدفوعات أو استخدام تجاري مختلف عن عرض الأعمال.
- خط Cairo مضمن محليًا، ورخصته في `assets/FONT-LICENSE.txt`. احتفظ بها مع الملفات.
